\# Estruturas de Dados Fundamentais em C



## Objetivo
Guiar o leitor na implementação de estruturas de dados dinâmicas em C, com ênfase em ponteiros e alocação de memória.

\## Público-alvo

Estudantes de graduação que já sabem a sintaxe básica de C, mas ainda não trabalharam com ponteiros aplicados a estruturas dinâmicas.



\## Pré-requisitos

\- Sintaxe básica de C (variáveis, funções, structs)

\- Noções de ponteiros
