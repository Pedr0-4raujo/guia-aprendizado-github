\# Estruturas de Dados Fundamentais em C



\## Objetivo

Ensinar estudantes de graduação a implementar listas encadeadas, pilhas e filas em C, dominando alocação dinâmica de memória e as operações básicas de inserção, remoção e percurso.



\## Público-alvo

Estudantes de graduação que já sabem a sintaxe básica de C, mas ainda não trabalharam com ponteiros aplicados a estruturas dinâmicas.



\## Pré-requisitos

\- Sintaxe básica de C (variáveis, funções, structs)

\- Noções de ponteiros
