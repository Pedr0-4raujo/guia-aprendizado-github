\# Estruturas de Dados Fundamentais em C



## Objetivo
Apresentar de forma prática os conceitos de listas encadeadas, pilhas e filas em linguagem C, com foco em exercícios e exemplos de código.


\## Público-alvo

Estudantes de graduação que já sabem a sintaxe básica de C, mas ainda não trabalharam com ponteiros aplicados a estruturas dinâmicas.



\## Pré-requisitos

\- Sintaxe básica de C (variáveis, funções, structs)

\- Noções de ponteiros



\## Estrutura

1\. Introdução

2\. Conceitos

3\. Exercícios

4\. Referências



\## Como navegar

Comece por `docs/01-introducao.md` e siga a ordem numérica dos arquivos em `docs/`.
